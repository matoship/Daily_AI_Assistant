Claude Code Gets Formal Plugin Evaluation Framework with CI Gating

Anthropic has introduced a structured evaluation system for Claude Code plugins, featuring six distinct grader types, a no-plugin baseline for comparison, and a CI gate that can block skill regressions before they ship. This brings software-engineering-style testing rigor to the plugin/skill ecosystem surrounding coding agents.

Why it matters: As you build LLM applications on ServiceNow, having a repeatable eval + CI pattern for agent skills is directly transferable to your own pipelines. This is a concrete template for how to test and gate AI agent capabilities in production, which is core to the AI Application Engineer path.

Google's ToolGrad Hits 99.8% Pass Rate Generating Tool-Use Training Data

Google Research released ToolGrad, an 'answer-first' framework for synthesizing high-quality tool-use training data for LLMs, achieving a 99.8% pass rate. Instead of generating a query and hoping the model calls tools correctly, the framework works backward from a valid answer/tool-call trace, drastically improving data quality for fine-tuning tool-using agents.

Why it matters: For engineers building LLM apps that rely on function/tool calling (e.g., ServiceNow integrations), this offers a practical method to generate reliable training or eval data for improving tool-use accuracy in your own agents.

ByteDance Study: LLMs Struggle to Reliably Improve Their Own Agent Harness

ByteDance Seed's HarnessDev project tested whether LLMs can self-engineer improvements to their own agent scaffolding/harness. Of 64 proposed changes, only 34 generalized well to new tasks, highlighting the gap between locally-plausible self-modifications and genuinely robust improvements.

Why it matters: This is a useful reality check for anyone iterating on agent harnesses or prompt/tooling scaffolds for LLM applications—self-improvement loops need strong generalization testing, not just single-task validation, before trusting automated changes to production agent infrastructure.
