LEANN Slashes RAG Vector Index Size by 97% Without Sacrificing Recall

Researchers introduced LEANN, an open-source vector indexing method accepted at MLSys 2026, that compresses a 60-million-chunk RAG index from 201GB down to just 6GB by using graph-based recomputation instead of storing full embeddings, while maintaining retrieval accuracy.

Why it matters: For LLM application work involving retrieval-augmented generation, this kind of storage efficiency is a game-changer for deploying RAG systems in resource-constrained or enterprise environments like ServiceNow instances, where infrastructure costs and scalability matter a lot.
