StepFun Drops Step 5 Preview: 600B MoE Model with 1M Context Window, Fully Open Weights

StepFun has released open weights for Step 5 Preview, a massive Mixture-of-Experts (MoE) model with 600B total parameters but only 27B active per inference pass, paired with a 1 million token context window. The MoE architecture keeps compute costs manageable despite the huge total parameter count, and the long context makes it suitable for tasks requiring large document or codebase ingestion.

Why it matters: As an AI engineer building LLM applications, open-weight MoE models with huge context windows are directly relevant to your work—they expand what's feasible for RAG-free long-context applications and give you another self-hostable option to evaluate against commercial APIs for ServiceNow integrations or custom agent pipelines.

Perplexity Open-Sources SPACE: A Firecracker MicroVM Sandbox for AI Agents

Perplexity has open-sourced SPACE, a sandboxing solution built on Firecracker microVMs designed to safely isolate and execute code generated or run by AI agents. The project aims to give developers a secure, lightweight environment for agentic workloads that need to execute arbitrary code.

Why it matters: Sandboxing is a core infrastructure concern for anyone building agentic LLM applications—this gives you a concrete, production-grade pattern to consider if you're architecting agents that need to execute code safely, relevant to your AI Application Engineer trajectory.
