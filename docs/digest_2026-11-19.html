Anthropic Gives Claude Code 'Code Mode' for Chained JavaScript Tool Calls

Anthropic has introduced a new 'Code Mode' for Claude Code that allows the model to chain multiple tool calls together using generated JavaScript instead of issuing them one at a time. This lets Claude plan and execute multi-step workflows (file edits, API calls, shell commands) more efficiently within a single coherent script rather than through repeated back-and-forth tool invocations.

Why it matters: As an AI Engineer building LLM applications on ServiceNow, this directly impacts how you might design agentic workflows and tool orchestration. Chaining tool calls via code rather than discrete turns could simplify building more reliable multi-step automations, which is core to your path toward becoming an AI Application Engineer.

LoRA Adapter Boosts Qwen3.8 Coding Accuracy from 39% to 65%

A new LoRA (Low-Rank Adaptation) adapter released via Hugging Face significantly improves the coding task success rate of the Qwen3.8 (27B) model, jumping from 39% to 65% on benchmark evaluations, without full model retraining.

Why it matters: This is a practical example of efficient fine-tuning that can make smaller open models competitive for coding/agentic tasks—relevant if you're evaluating cost-effective LLM options for application engineering work instead of relying solely on large proprietary models.

SID AI Launches SID-2 Agentic Search Model with Swarm Mode

SID AI has released SID-2, an agentic search model achieving a 0.720 NDCG score, featuring a new 'Swarm Mode' that coordinates multiple search agents collaboratively to improve retrieval quality and relevance ranking.

Why it matters: Agentic search and multi-agent coordination patterns like 'Swarm Mode' are increasingly relevant to building retrieval-augmented LLM applications—useful knowledge for designing smarter search/retrieval layers in your own AI application projects.
