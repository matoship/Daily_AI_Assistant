Agentic AI Tooling Push Forward: Coding Evals, Agent Frameworks, and Open MoE Models

Several engineering releases landed this week around agentic AI and LLM infrastructure. Supabase open-sourced 'Evals,' a benchmark that scores coding agents like Claude Code, Codex, and OpenCode on real-world Supabase backend tasks. Microsoft's Agent Framework Harness and Hosted Agents reached General Availability, giving developers a production-ready platform for building and deploying multi-agent systems. NVIDIA released Molt, a PyTorch-native framework for agentic reinforcement learning, aimed at training AI agents that can reason and act over multi-step tasks. AMD also released Instella-MoE-16B-A3B, a fully open mixture-of-experts LLM with 2.8B active parameters trained on Instinct GPUs, expanding the open-model ecosystem beyond NVIDIA-centric training stacks. Separately, an InfoQ presentation discussed 'agentic compute' as a missing architectural layer for deploying AI systems reliably inside messy enterprise environments.

Why it matters: As an AI Engineer working on ServiceNow/LLM applications and aiming to become an AI Application Engineer, these releases are directly relevant: benchmarks like Supabase Evals help you evaluate coding agents objectively, Microsoft's GA agent framework offers a template for production-grade agent architecture, and the enterprise-focused 'agentic compute' talk speaks to real deployment challenges you're likely facing. The open MoE models (AMD, NVIDIA tooling) also expand your options for experimenting with open-source LLM infrastructure outside proprietary stacks.

Australia Overhauls Skilled Migration System for 2026/27: Higher Income Thresholds, New Processing Priorities

Australia is rolling out significant changes to its skilled migration system for 2026/27. The government has raised the minimum income requirement for skilled work visas, releasing updated salary figures applicants must meet. Alongside this, a new Ministerial Direction (119) introduces revised processing priorities for skilled visas, with onshore applicants (those already in Australia) now prioritized over offshore candidates. These changes come as Australia faces labor shortages across health, industry, retail, and hospitality sectors, prompting an expanded search for foreign workers even as entry requirements tighten. The broader 2026/27 migration plan signals continued reliance on skilled migrants to fill workforce gaps despite the higher income bar.

Why it matters: As someone based in Adelaide navigating Australia's immigration system, these changes directly affect your visa planning: higher income thresholds could impact eligibility for skilled visa pathways, while the new onshore-priority processing rules under Direction 119 may work in your favor if you're already in Australia. Understanding these shifts is critical for timing any visa applications or renewals tied to your career progression as an AI Engineer.
