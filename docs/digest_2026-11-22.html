OpenAI's GPT-Live-1.1 Slashes Idle Costs for Voice Agents

OpenAI released GPT-Live-1.1, an updated API for building voice agents, introducing a 'standby mode' that cuts idle compute costs to just $0.02/minute. This makes it dramatically cheaper to keep voice-based AI agents running and ready to respond without paying full inference costs while waiting for user input.

Why it matters: As someone building LLM applications on ServiceNow, cost-efficient voice agent infrastructure is directly relevant if you're exploring conversational interfaces for enterprise workflows. The standby mode pattern could also inform how you architect idle-state handling for your own agentic applications, supporting your path toward becoming an AI Application Engineer.

LLMs Demonstrate Ability to Read and Write Machine Code Byte-by-Byte

A blog post details experiments showing LLMs can parse and generate executable binaries directly from hex dumps, effectively reading and writing machine code without going through traditional assembly or compiler toolchains. This pushes the boundary of what LLMs can manipulate beyond natural language and high-level source code.

Why it matters: This is a striking example of how far LLM capabilities extend into low-level systems engineering, which is useful context when evaluating what's technically feasible for advanced AI application features—including potential use cases like automated binary analysis or security tooling in enterprise AI products.

Thinking Machines' Inkling-2-Mini Brings 26B Looped MoE Model to Consumer Macs

Thinking Machines released Inkling-2-Mini, a 26B-parameter looped Mixture-of-Experts model designed to run on a 32GB Mac. A companion quantized build (GitHub: lookatmyquant) further compresses the model to run in just 5.4 GB of memory, making it accessible on much more modest hardware.

Why it matters: Running large models locally on consumer hardware is directly relevant to your work building LLM applications—it signals a growing feasibility of on-device or edge deployment for enterprise AI tools, reducing dependency on cloud inference and potentially lowering costs for ServiceNow-integrated LLM features.

Baseten's Bison-1 and Groundhog-1 Top Decision Model Benchmarks

Baseten launched two new models, Bison-1 and Groundhog-1, which now lead the Decision Model Index, outperforming Gemma-4 on decision-making benchmark tasks.

Why it matters: Decision models are highly relevant to enterprise workflow automation—exactly the kind of capability that could enhance ServiceNow-based LLM applications where structured decision-making (e.g., ticket routing, approvals) is central to the product value, aligning well with your AI Application Engineer trajectory.
