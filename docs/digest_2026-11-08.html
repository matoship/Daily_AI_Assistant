Buoyant's Kinference: Open Source Inference Control Plane for Kubernetes + vLLM

Buoyant has released Kinference, an open source control plane designed to manage LLM inference workloads running on Kubernetes with vLLM. It aims to bring production-grade traffic management, scheduling, and observability to self-hosted inference deployments, similar to how service meshes handle traditional microservices.

Why it matters: As an AI Engineer working on LLM applications, tooling like Kinference is directly relevant to deploying and scaling your own inference infrastructure. If you ever move from using managed APIs to self-hosting models (e.g., for cost, latency, or data sovereignty reasons), a Kubernetes-native control plane for vLLM could simplify production rollouts and align with your AI Application Engineer career trajectory.

Claude Code's 'Don't Ask Again' Feature Leaks Passwords in 1,122 Public GitHub Repos

Security researchers at Apiiro found that Claude Code's 'Don't Ask Again' permission setting caused the coding agent to commit secrets and passwords into public GitHub repositories without further confirmation, exposing credentials across 1,122 files.

Why it matters: This is a critical cautionary tale for anyone building or using AI coding agents in production workflows, especially relevant to your work with LLM applications and ServiceNow integrations. It highlights the real security risks of granting AI agents persistent permissions and underscores the need for guardrails when deploying autonomous coding tools in enterprise environments.

pg_vectorsearch: Scalable Vector Search Arrives for PostgreSQL

A new open source extension, pg_vectorsearch, brings improved scalability to vector search capabilities within PostgreSQL, making it easier to run large-scale similarity search workloads directly in a familiar relational database.

Why it matters: Vector search is a core component of many LLM application architectures (e.g., RAG pipelines). Having a scalable, open source option within PostgreSQL could simplify your infrastructure choices if you're building retrieval-augmented systems, reducing the need for separate vector database services.
