OpenAI Launches 'dots': Always-On GPT-6 Astra Agents Running on Their Own Cloud Machines

OpenAI has introduced 'dots,' a new agent framework built on GPT-6 Astra that runs persistently on dedicated cloud compute rather than spinning up on-demand per session. These always-on agents can maintain state, monitor tasks continuously, and act autonomously over long horizons, effectively giving each agent its own 'computer' to operate from. OpenAI's own announcement page corroborates the launch details and framing of dots as a new agent runtime paradigm.

Why it matters: As someone building LLM applications on ServiceNow and working toward an AI Application Engineer role, always-on agent architectures are directly relevant to how you'll design production agent workflows—especially for long-running enterprise automations that need persistent state and continuous monitoring rather than stateless request/response calls.

Google Open-Sources RRSI: Agents That Self-Improve Their Own Harness Without Overfitting

Google Research released RRSI (an open-source technique/framework), which allows AI agents to iteratively refine their own operating harness—the scaffolding of prompts, tools, and control logic around a model—while avoiding overfitting to specific benchmarks or tasks. This addresses a key challenge in agent engineering: how to let agents adapt their own tooling and instructions safely over time.

Why it matters: Self-improving harnesses are highly relevant to your work building LLM applications, since designing and tuning agent scaffolding (prompts, tool definitions, control flow) is a core engineering task. A generalizable method for safe self-improvement could inform how you iterate on ServiceNow agent configurations without manual re-tuning for every new use case.

H Company Releases Holo4: Open-Weight Computer-Use Models Spanning Desktop, Web, Android, and APIs

H Company has released Holo4, a family of open-weight models designed for 'computer use'—clicking through UIs, writing and executing code, and calling external tools across desktop, web, Android, and API surfaces. This positions Holo4 as a competitor to closed computer-use models, giving developers open access to build autonomous UI-interacting agents.

Why it matters: Open-weight computer-use models are a practical resource for AI Application Engineering, particularly if you need to prototype or self-host agents that automate GUI-based enterprise workflows (e.g., legacy systems without APIs) rather than relying solely on closed vendor models.

Anthropic's Claude Sonnet 5.5 Hits 70.6% on Terminal-Bench 4.0, Same Price as Predecessor

Anthropic released Claude Sonnet 5.5, achieving a 70.6% score on Terminal-Bench 4.0 (a benchmark for terminal/coding-agent tasks) while keeping pricing unchanged at $2/$10 per million input/output tokens. This represents a capability jump for agentic coding and terminal-based tasks without added cost.

Why it matters: Improved terminal-bench performance at stable pricing directly benefits your LLM application development work, as it suggests better reliability for coding/automation agents you might integrate into ServiceNow workflows—without increasing your API cost budget.
