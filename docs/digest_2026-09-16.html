Google Ships Gemini 3.8 Live and Live Extended Thinking for Production Voice Agents

Google has released Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking, a pair of models aimed at powering production-grade, real-time voice agents. The Extended Thinking variant adds deeper reasoning capability before responding, while the base Live model focuses on low-latency conversational performance. Google's own blog and MarkTechPost both cover the launch, framing it as a step toward enterprise-ready conversational AI that can handle complex, multi-turn voice interactions reliably.

Why it matters: As you build LLM-based applications on ServiceNow, voice-capable agent models with a 'thinking' mode are directly relevant to designing production AI agents (e.g., voice-driven ITSM workflows). Understanding the tradeoffs between the fast Live model and the reasoning-heavy Extended Thinking variant will help you architect agent systems that balance latency and accuracy — a core skill for moving toward an AI Application Engineer role.

Agent-net Open Sources 'Webagent': A Go-Based Guarded Browsing Harness for AI Agents

Agent-net has open-sourced Webagent, a harness written in Go that lets AI agents interact with any website through a 'guarded' interface, adding safety constraints and structure to otherwise unconstrained web browsing by autonomous agents. The project aims to make web automation safer and more predictable for agentic use cases.

Why it matters: Guardrails for agent-driven web interaction are a practical concern when building enterprise LLM applications that need to safely automate tasks across web-based systems, similar to workflows you might design in ServiceNow. This kind of harness pattern is useful reference architecture for constraining agent actions in production.

Grab Launches LLM-Kit to Speed Up AI Agent Deployment

Ride-hailing and delivery company Grab has introduced an internal agent framework called LLM-Kit, designed to accelerate the production deployment of AI agents across its platform. The framework standardizes tooling and patterns for building and shipping agents at scale within Grab's engineering organization.

Why it matters: Seeing how a large tech company standardizes agent development and deployment offers useful patterns for your own work building LLM applications on ServiceNow — particularly around frameworks that reduce time-to-production for agentic features.
