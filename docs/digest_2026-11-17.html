Uber Cuts Contract Review Time 20% with Rules-Based + RAG Legal AI Agent

Uber built an internal legal AI agent that automates contract redlining by combining deterministic rule engines with retrieval-augmented generation (RAG). The hybrid approach lets the system apply hard legal/compliance rules precisely while using RAG to pull relevant contract clauses and precedent language, cutting legal contract review time by 20% without sacrificing accuracy.

Why it matters: This is a strong real-world example of combining RAG with rule-based logic to build reliable enterprise agents—directly relevant to your work building LLM applications on ServiceNow, where similar hybrid patterns (deterministic workflow logic + generative retrieval) are key to production-grade AI agents.

Meta's JiTTests: LLM-Generated Tests That Try to Break Risky Code Before It Ships

Meta introduced JiTTests, a system that uses LLMs to generate 'just-in-time' tests specifically designed to fail on risky or privacy-sensitive code changes before they're merged. The approach targets catching subtle bugs (like privacy violations) that traditional test suites often miss, by having the LLM reason about what could go wrong with a given diff and writing adversarial tests accordingly.

Why it matters: As LLM-driven development tooling matures, this shows how generative AI can be applied to software quality and safety gates—useful context for engineering robust AI-assisted development pipelines and for thinking about how to harden your own LLM application code against edge cases.
