Untangling the Agent Stack: Harness vs Framework vs MCP

This piece breaks down the emerging layers of AI agent architecture — the 'harness' (loop and execution control), the 'framework' (state, tools, orchestration), and MCP (Model Context Protocol, which standardizes tool/permission access). It clarifies which layer is responsible for owning the agent loop, managing state, invoking tools, enforcing permissions, and handling recovery from failures, offering a mental model for architects building production-grade agentic systems.

Why it matters: As you build LLM-based applications on ServiceNow and move toward becoming an AI Application Engineer, understanding where responsibilities sit in the agent stack (harness vs framework vs MCP) is directly relevant to designing robust, maintainable agentic workflows — especially around permissions and failure recovery, which matter a lot in enterprise contexts like ServiceNow.
